# Lucide 图标库 · MasterGo 插件

> 在 MasterGo 面板里，用和前端代码完全同名的方式找到 Lucide 图标，按设计规范调好尺寸与描边，拖到画布上——拿到的是一份可继续编辑的矢量图层，而不是一张图。

[Lucide](https://github.com/lucide-icons/lucide) 是 shadcn/ui、Tailwind CSS 等现代前端生态广泛使用的开源图标集。这个插件让你在设计稿里拖入的图标，与前端代码里写的是同一套图形——交付时不会出现「设计稿和线上不一致」。

## 功能特性

- **与代码同名**：搜索框里输入 `house`，拿到的就是代码里 `<House />` 渲染的那个图标
- **绝对描边宽度**：公式 `strokeWidth × 24 / size`，与 lucide.dev 及源码逐字对齐，改尺寸不改变描边的视觉粗细
- **官方分类 + 官方 tag**：沿用 Lucide 的 42 个分类与 4000+ 个官方 tag；并并入 264 个官方旧名，命中时提示「已改名为 xxx」
- **中文可搜**：内置词典（1806 条），输入「设置」也能搜到 `settings`；分类栏优先显示中文名
- **矢量可编辑**：拖入画布后是真实的矢量图层树，描边色、图层名均可继续编辑
- **默认色跟着主题走**：面板是深色底时默认描边色取白、浅色底时取黑，打开就能看清，不会被同色底吃掉
- **离线内置**：1847 个图标全量内置，运行时零网络请求
- **参数记忆**：尺寸 / 描边 / 颜色 / 所在分类 / 样式条折叠状态跨会话保留

## 安装与使用

### 安装

在 MasterGo 插件市场搜索「Lucide 图标库」安装即可（需 MasterGo 桌面客户端）。

### 使用

1. **打开面板** —— 插件菜单 → Lucide 图标库
2. **找图标** —— 搜索框输入英文名（`house`）或中文（`设置`）；也可以用左侧分类栏按官方分类浏览
3. **调样式** —— 在样式条里设尺寸（16–96）、描边（0.5–6）与颜色。开启「绝对描边宽度」后，把图标放大不会让描边看起来更粗
4. **导入** —— 两种方式：
   - **拖拽**：把图标拖到画布上的任意位置
   - **点击**：先选中一个容器或画框，再点图标，会插入到该容器内；未选中任何图层时插入到当前页面
5. **继续编辑** —— 导入结果是矢量图层（一个容器 + 内部矢量路径），描边色、粗细、尺寸都可以接着改

## 常见问题

**导入的图标看不见？**
描边色默认跟随面板主题（深色面板 → 白色，浅色面板 → 黑色）。如果画布是浅色的，插入的白图标会看不见——用样式条的颜色选择器改一次即可，改完会记住。

**需要联网吗？**
不需要。1847 个图标的几何与分类数据全部内置在插件里，运行时零网络请求，断网也能正常使用。

**面板是深色还是浅色？**
跟随操作系统的外观设置（macOS：系统设置 → 外观）。MasterGo 客户端内部的深色主题目前感知不到。

**参数会记住吗？**
会。尺寸、描边、颜色、上次所在的分类、样式条折叠状态都跨会话保留。

## 技术栈

- Vue 3.2 + TypeScript 5
- Vite 2.9 + vite-plugin-singlefile
- MasterGo Plugin API（`createNodeFromSvgAsync` / `on('drop')` / `clientStorage` / `commitUndo`）

## 开发

```bash
npm install
npm run typecheck   # 类型检查
npm run build       # 产出 dist/
npm run dev         # 双 watch（UI + 主线程）
```

构建产物在 `dist/` 下，包含 `index.html`（UI）与 `main.js`（主线程），均为单文件内联。

在 MasterGo 客户端中加载调试、项目结构说明，以及几条**必须遵守的构建约束**，见 [CONTRIBUTING.md](./CONTRIBUTING.md)。
